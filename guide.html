1安装Installation

macOS（Apple 芯片） (Apple Silicon)

  1. 双击 .dmg 安装包 → 把「知脉 ZhiMai」图标拖进 Applications 文件夹。
  2. 在 启动台 / Launchpad 里找到「知脉 ZhiMai」，双击启动。
  3. 若提示「无法验证开发者」：苹果菜单 → 系统设置 → 隐私与安全性 → 滚到底部 → 仍要打开 → 输一次 Mac 密码。
  4. 正常使用过程中不会再反复要密码（v0.9.1 已修）。
  1. Double-click the .dmg → drag the "知脉 ZhiMai" icon into Applications.
  2. Find it in Launchpad and double-click to launch.
  3. If "Cannot verify developer": Apple menu → System Settings → Privacy & Security → scroll down → Open Anyway → enter your Mac password once.
  4. During normal use it will not keep asking for a password (fixed in v0.9.1).

Windows x64

  1. 双击 .exe 安装包。
  2. 若 SmartScreen 提示「未知发布者」：点「更多信息」→「仍要运行」。没买代码签名，不是病毒，仅首次出现。
  3. 安装向导一路「下一步」用默认即可；首次启动若缺 WebView2 会自动下载安装。
  1. Double-click the .exe.
  2. If SmartScreen says "Unknown publisher": click "More info" → "Run anyway". No code signing yet, not a virus, first time only.
  3. Installer wizard → "Next" with defaults; if WebView2 is missing on first launch it auto-installs.
应用还没买代码签名证书（独立开发者，证书在路上），所以两端首次打开都要手动放行一次。这是正常的，不是病毒。The app isn't code-signed yet (indie developer, certificate on the way), so you approve it once on first open on each OS. This is expected — not a virus.

2首次配置First-launch setup

① 配一个 AI 模型① Configure an AI model 必做required

  1. 点左下角 ⚙️「设置」。
  2. 找到「AI 模型提供方」。
  3. 提供方下拉，四选一：DeepSeek / OpenAI / Claude (Anthropic) / Azure OpenAI。
  4. 粘贴对应的 API Key，模型保持默认。
  5. 点「保存并测试」→ 出现成功提示就配好了。
  1. Click ⚙️ "Settings" (bottom-left).
  2. Find "AI model provider".
  3. Provider dropdown, pick one: DeepSeek / OpenAI / Claude (Anthropic) / Azure OpenAI.
  4. Paste the matching API key, leave Model on default.
  5. Click "Save and verify" → a success message means you're set.
入门推荐 DeepSeek（注册 platform.deepseek.com，便宜稳定）。你的 Key 存在自己电脑的本地文件里，不上云——这也是为什么 v0.9.1 不再反复弹密码框。DeepSeek is the easiest start (register at platform.deepseek.com). Your key is stored in a local file on your own computer, never the cloud — which is why v0.9.1 no longer triggers the password popup.

② 选界面语言② Choose interface language

设置 →「界面语言」→ 选 简体中文 或 English。生成的报告也跟着这个语言。也可以从底部状态栏的语言按钮快速切换。Settings → "Interface language" → pick 简体中文 or English. Reports follow this language. You can also toggle it from the language button in the bottom status bar.

③ （可选）配向量模型，开启智能问答③ (Optional) Embedding model for chat

智能问答需要向量模型。设置 →「向量模型 (RAG)」→ 选 Jina v3（注册 jina.ai，每月免费 100 万 tokens）→ 粘贴 Key →「保存向量模型 Key」。不配也能用其它功能，只是智能问答不可用。Knowledge chat needs an embedding model. Settings → "Embedding model (RAG)" → pick Jina v3 (free 100M tokens/mo at jina.ai) → paste key → "Save embedding key". Optional — everything else works without it.

④ 知识库位置④ Knowledge base location

默认已自动准备好，一般不用动。想换：设置 →「本地知识库」→「高级：更改位置」→「选择文件夹」→「保存新位置」。别选系统目录或已有重要文件的目录。Auto-prepared by default — usually leave it alone. To change: Settings → "Local knowledge base" → "Advanced: change location" → "Pick folder" → "Save new location". Don't pick system folders or folders with important files.

3三大功能区The three zones

主导航分三块：采集 → 探索 → 研究报告。一句话：采集喂料、探索消化、研究报告产出。Three zones: Capture → Explore → Reports. In one line: Capture feeds it, Explore digests, Reports produces.

采集 — 把信息丢进去Capture — feed it information

两个标签：「收件箱」看所有采进来的内容，「数据源」配置从哪采。支持 5 种来源：Two tabs: "Inbox" shows everything captured, "Sources" configures where to capture from. Five source types:

来源Source怎么用How
网页采集Web page粘贴文章链接 → 采集网页Paste an article URL → Capture page
YouTube粘贴视频链接，自动抓字幕，免 API KeyPaste a video URL, auto-grabs transcript, no key
Telegram填 Bot Token，之后转发消息给 bot 自动入库Paste a Bot Token, then forward messages to the bot
RSS填 Feed 链接，自动定期抓Paste a feed URL, auto-polled
PDF直接把文件拖进窗口 / 选择文件Drag a file in / pick file

采进来后你什么都不用做：AI 自动读完、写摘要、打标签、抽取人/公司/概念、建索引。卡片状态从「待处理」变「已处理」。用「同步信息源」拉新内容、「处理选中」批量跑。After capture you do nothing: AI reads it, summarizes, tags, extracts people/companies/concepts, indexes it. Cards go from "Pending" to "Processed". Use "Sync sources" to pull new items and "Process selected" to batch-run.

Telegram 在中国大陆默认连不上，需要梯子。这是网络限制，不是知脉的 bug。Telegram is blocked by default in mainland China — needs a VPN. A network limit, not a ZhiMai bug.

探索 — 消化成知识Explore — digest into knowledge

  • 智能问答Knowledge chat（需先配向量模型needs embedding）— 直接问问题，它从整个知识库语义检索 + 大模型综合回答 + 附来源。Ask in plain language; semantic retrieval over your whole base + LLM synthesis + citations.
  • Wiki — AI 根据你采集的内容自动生成并维护的结构化词条，每个观点标了出处，点一下跳回原文。别手动改，下次会被覆盖。Structured entries auto-written and maintained by the AI. Every point cites its source — click to jump back. Don't hand-edit; they get overwritten.
  • 实体库Entities — 所有抽取出的实体（人、公司、概念）+ 提及次数 + 相关采集。All extracted entities with mention counts and references.
  • 深度研究Deep Research（v0.9.1 核心the centerpiece）— 输入一个主题 → 点「开始研究」。它拆子问题 → 检索你的知识库 → 综合成一篇带来源引用的研究报告。约 30–60 秒，别关页面。Enter a topic → "Start Research". It breaks down sub-questions → searches your base → synthesizes a cited report. ~30–60s, keep the page open.
  • 知识图谱Knowledge graph（⌘\）— 实体关系网，右侧洞察面板告诉你哪些是连接不同领域的「桥梁」、哪些是反复提到却没深入的盲点。Entity network; the insight panel surfaces "bridge" concepts and blind spots.

研究报告 — 正式交付物Reports — formal deliverables

要更正式、可视化的交付物时用这块。三步：Use this for formal, visual deliverables. Three steps:

  1. 准备素材 — 同步来源、处理待办，确保材料可用。
  2. 选择材料 — 勾选这次报告要用的采集内容。
  3. 生成报告 — 选一个模板，点生成。
  1. Prepare material — sync sources, clear the pending queue.
  2. Select captures — tick what this report should draw on.
  3. Generate — pick a template and generate.

四个模板：行业研究 / 公司研究 / 竞品分析 / 周报总结。「生成研究报告」出 Markdown 文字版；「视觉研报」出一张能一眼看完、可直接截图发同事的可视化报告。界面是中文就出中文，英文就出英文。Four templates: Industry Research / Company Research / Competitive Analysis / Weekly Digest. "Generate report" gives a Markdown version; "Visual report" gives a one-glance visual you can screenshot into a deck. Output language follows your interface language.

6数据与隐私Data & privacy

  • 资料不上传Material never uploaded — 采集的原文、整理的知识、生成的报告，全部存在你自己电脑上。your captured text, organized knowledge, and reports all live on your own computer.
  • 密钥本地保存Keys stored locally — API Key 存在你电脑的本地文件里，不上云——所以不再反复弹密码框。API keys sit in a local file on your machine, never the cloud — which is why the password popup is gone.
  • 只有 AI 调用会出网Only LLM calls leave the device — 跑 AI 时会把相关内容发给你选的模型厂商（DeepSeek/OpenAI/Claude/Azure），受各家隐私政策保护。running AI sends relevant content to your chosen provider, under their privacy policies.
  • 备份Backup — 把知识库文件夹加进 iCloud / OneDrive / Time Machine 即可。add the knowledge base folder to iCloud / OneDrive / Time Machine.
  • 数据带得走Your data is portable — 知识库就是一个普通文件夹，全是标准 Markdown，卸载知脉后用任何编辑器都能继续打开。the knowledge base is a plain folder of standard Markdown — open it in any editor even after uninstalling.
