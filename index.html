为什么需要它

你不是没读，
是读完就丢了。

每天几十个标签页、收藏夹、转发给自己的链接。当时觉得有用，过两周再也找不到，也想不起来当时为什么觉得它重要。

01

收藏 = 永久遗忘

存进去那一刻，往往就是你最后一次看它。收藏夹越攒越厚，真要用的时候一条都想不起来。

02

信息散成一地

YouTube 在浏览器、PDF 在下载文件夹、好文章在 Telegram。没有一个地方把它们串起来。

03

AI 工具要先把你的数据交出去

大部分 AI 笔记得把你的私密资料上传到别人的服务器。你的阅读史、研究方向，凭什么给它。

它怎么工作

你只管丢进来，剩下交给它。

第一步

采集

粘贴 YouTube 链接 / 网页 URL，或丢进 PDF、接上 Telegram、RSS。一步入库，抓字幕不用配 API Key。

第二步

自动分析

每条进来，LLM 立刻读完、抽出实体和概念、打标签——不用你点「开始处理」。

第三步

自动建库

自动生成 / 更新 wiki 词条，标好来源出处，和你库里已有的知识互相连上。

第四步

深度研究

给一个主题，它自己拆子问题、在你的库里多轮检索，写出一份带引用的研究报告。

下载前，先答疑

点下载之前，
你大概想先问清楚这几件事。

要钱吗？

软件本身免费。我是独立开发者，自己每天在用，没打算靠它收订阅费。

唯一的花费是 AI——知脉不内置模型，用的是你自己的 LLM API Key（Claude / OpenAI / DeepSeek / Azure 任选其一）。读文章、写报告这些 AI 动作，按各家平台的用量计费，钱直接付给模型厂商，不经我手。DeepSeek 这类便宜的，重度用一个月通常也就几块到几十块。

我的数据安全吗？存在哪？

数据全在你自己电脑上。知脉是 local-first 的——采集进来的内容、生成的词条、整个知识库，都是你硬盘上一堆标准 markdown 文件（默认放在 ~/Documents/ZhiMai-Vault），用 Obsidian 能直接打开。我没有服务器，也收不到你的任何数据。

唯一会"出门"的时刻：当你主动触发 AI 分析或写报告时，这一次需要的那部分内容会发给你自己配的那家 LLM。发给谁、发什么，都是你点的那一下决定的，没有后台偷偷上传。

打开时提示"无法验证开发者"怎么办？

正常，别慌。安装包还没买苹果签名证书（一个独立开发者一年好几百，等用的人多点再说），所以 macOS 首次会拦一下。

解决很简单：右键点应用图标 → 选「打开」，弹窗里再确认一次「打开」，之后就跟普通 app 一样双击用了，只需要做这一次。介意的话，源码全在 GitHub 上公开，可以先翻一翻。

需要联网吗？要准备什么？

采集、检索、看库这些都在本地。但只要用到 AI（自动分析、深度研究、智能搜索），就需要联网去调你选的那个大模型——这一步绕不开。

开始前要准备一样东西：一个 LLM API Key。去 Claude / OpenAI / DeepSeek 任意一家官网注册、充点钱、生成一个 key，第一次打开知脉时填进设置里就行。不会配的话，GitHub 上有一步步的图文说明。

Windows 版什么时候有？

正在路上，先做的 Mac（Apple Silicon）。技术栈是跨平台的（Tauri + Rust），Windows 版的打包和测试在做了，好了第一时间放上来。想催的话，发我封邮件，人多我就排前面。

哪天不想用了，数据带得走吗？

带得走，原封不动。知识库就是一个普通文件夹，里面全是标准 markdown，没有私有数据库、没有加密锁定。卸载知脉，那个文件夹还在，Obsidian、VS Code、甚至记事本都能继续读。不绑架你的数据，是这东西设计时的底线。

还有别的疑问？直接发邮件问我，或者去 GitHub 提 issue。
